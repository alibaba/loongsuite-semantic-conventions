[A2A (Agent-to-Agent)](https://github.com/google/A2A) is a JSON-RPC based protocol for inter-agent communication. It defines standard methods for agents to exchange messages and manage tasks.

### Span name

**Span name** SHOULD be `{gen_ai.a2a.rpc.method}` (e.g., `message/send`, `tasks/get`).

### RPC Methods

Common A2A JSON-RPC methods include:

| Method | Description |
| --- | --- |
| `message/send` | Send a message to an agent |
| `tasks/get` | Get task status and result |
| `tasks/cancel` | Cancel a running task |

## A2A Task States

| State | Description |
| --- | --- |
| `submitted` | Task has been submitted |
| `working` | Task is currently being processed |
| `input-required` | Task requires additional input |
| `completed` | Task has completed successfully |
| `failed` | Task has failed |
| `canceled` | Task was canceled |
